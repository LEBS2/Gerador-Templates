How it works

1
Select the fake profile type
Choose between FSP (Fake Social Profile - fake social media profile) or EFSP (Executive Fake Profile - an executive or leader being impersonated).
2
Say whether it is a first notice or a follow-up notice
First notice: profile not reported yet. Follow-up notice: follow-up on a previous report that is still active.
3
Fill in the report details
Enter the client name, the fake profile URLs and the date. The system automatically generates the formatted template, ready to send.
4
Copy and send the report
Copy the generated text and forward it through the indicated channel (WhatsApp, email or the social network's platform). The history is kept for follow-up.

What's the difference?

First notice
  • Profile has not been reported before
  • Opens a new case on the platform
  • Includes full identification of the profile
  • Template worded as a first occurrence
Follow-up notice
  • Profile was already reported and is still active
  • Follow-up on an existing case
  • References the previous report
  • Template worded as a repeat occurrence

If in doubt, choose First notice if this is the first report for this profile.
