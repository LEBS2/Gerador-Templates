Como funciona

1
Selecione o tipo de perfil falso
Escolha entre FSP (Fake Social Profile - perfil falso em redes sociais) ou EFSP (Executive Fake Profile - executivo ou liderança sendo falsificada).
2
Informe se é primeira notificação ou renotificação
Primeira notificação: perfil ainda não denunciado. Renotificação: seguimento de denúncia anterior ainda ativa.
3
Preencha os dados da denúncia
Informe o nome do cliente, as URLs do perfil falso e a data. O sistema gera automaticamente o template formatado pronto para envio.
4
Copie e envie a denúncia
Copie o texto gerado e encaminhe pelo canal indicado (WhatsApp, e-mail ou plataforma da rede social). O histórico fica registrado para acompanhamento.

Qual a diferença?

Primeira notificação
  • Perfil ainda não foi denunciado antes
  • Abertura de novo caso na plataforma
  • Inclui identificação completa do perfil
  • Template com linguagem de primeira ocorrência
Renotificação
  • Perfil já foi denunciado e continua ativo
  • Seguimento de caso já existente
  • Referencia a denúncia anterior
  • Template com linguagem de reincidência

Em caso de dúvida, escolha Primeira notificação se for o primeiro reporte deste perfil.
